# CampusCycle - Sprint 1 README

CampusCycle is a campus resource sharing platform designed around the theme **Sharing, Exchange and Building Community**. The aim of the application is to help students share, lend, swap, gift and discover useful academic and everyday items within the university community.

This Sprint 1 version focused on the early planning, project setup and initial idea development for the CampusCycle application. At this stage, the team concentrated on understanding the problem, defining the project concept, identifying users, planning the core features and setting up the initial repository structure.

---

## Project Overview

CampusCycle is intended to support students by reducing the cost of academic and daily-use resources. Instead of purchasing new textbooks, calculators, kitchenware, notes or equipment, students can use the platform to discover items shared by other students.

The project supports:

- student-to-student sharing
- borrowing and lending
- swapping useful items
- gifting free resources
- building a stronger campus community
- reducing waste through reuse

Sprint 1 was mainly a planning and setup sprint. The focus was not on a complete working application, but on preparing the foundation for later development.

## Initial User Stories

The early Sprint 1 user stories included:

### View Shared Resources

As a student, I want to browse available shared resources so that I can find useful items without needing to buy them new.

### View Listing Details

As a student, I want to view full details about a resource so that I can decide whether it is useful for me.

### View Student Profiles

As a student, I want to view the profile of the person sharing an item so that I can understand who owns the resource.

### Browse by Category

As a student, I want to browse items by category so that I can quickly find textbooks, notes, tools, equipment or daily-use items.

### Create a Listing

As a student, I want to create a listing so that I can share, lend, swap or gift an item to another student.

### Contact Another Student

As a student, I want to message another student about a listing so that I can ask questions or arrange collection.
