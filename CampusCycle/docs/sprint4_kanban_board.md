## Board columns

- `To Do`: tasks not started.
- `In Progress`: developer is actively working.
- `Review`: code is pushed but needs testing.
- `Done`: feature tested in Docker and screenshot captured.

## Important note

Each member should have visible assigned cards and visible commits. This is important because individual contribution is assessed through review attendance and GitHub metrics.
